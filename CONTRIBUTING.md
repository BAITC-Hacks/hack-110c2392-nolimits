# Работа над StockPilot

Команда работает параллельно. Для каждого изменения создавайте отдельную ветку от актуального `main`, делайте небольшие коммиты и открывайте pull request. Не перезаписывайте историю общей ветки через force push. Во время HackAlem AI 2026 публикуйте коммиты в официальный репозиторий не реже одного раза в час.

## Запуск и проверка

```bash
docker compose up --build
```

Интерфейс: `http://localhost:5173`, API: `http://localhost:8000/docs`.

Для проверки без Docker из корня репозитория:

```bash
python -m pip install -r backend/requirements.txt
python -m pytest -q backend/tests qa
cd frontend
npm ci
npm run build
```

В PR кратко опишите результат и выполненные проверки. При изменении API обновите `README.md` и тест; при изменении расчёта сохраните воспроизводимый сценарий в `qa/`. Не коммитьте локальные `.env`, SQLite, виртуальное окружение, `node_modules` и результаты сборки. Данные из `backend/data/` синтетические; пользовательские выгрузки и учётные данные храните только локально.
