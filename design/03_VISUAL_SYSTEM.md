# Визуальная система

## Направление

Рабочее название направления — «Зелёный контроль». Тёплые светлые поверхности, тёмная лесная навигация с лаймовым выделением, тёмная читаемая типографика, зелёный акцент для одного основного действия. Красный сообщает о подтверждённой проблеме, янтарный — о необходимости проверки, зелёный — о выполненном действии. Данные остаются главным визуальным содержимым.

Не использовать большой hero, орбиты, эмодзи как системные иконки, декоративные диаграммы и многоцветные KPI. Зелёный акцент не обозначает рост продаж; рост и падение спроса не равнозначны «хорошо» и «плохо».

## Сетка и плотность

| Элемент | Значение |
|---|---|
| Базовый шаг | 4 px; основной интервал 8 px |
| Ширина навигации | 224 px desktop, 72 px compact, off-canvas mobile |
| Верхняя панель | min-height 64 px, auto-height при переносе |
| Отступ рабочей области | 32 px ≥1440; 24 px 1024–1439; 16 px ≤767 |
| Максимальная ширина | 1760 px, центрирование контента на больших экранах |
| Промежуток крупных блоков | 24 px; связанных блоков 16 px |
| Строка таблицы | 64 px обычная двухстрочная, 48 px компактная |
| Контролы | 40 px обычные; 36 px компактные; touch 44 px |
| Панель товара | 600 px desktop; не более viewport; fullscreen на узком экране |
| Скругления | 6 px controls, 10 px cards, 12 px panels |
| Тени | Только overlay/popover; таблица отделяется border, не тенью |

На 1440×900 рабочие заголовки таблицы и минимум 4 строки должны быть видны без прокрутки. Это собственный критерий продукта, а не требование WCAG. На 1366×768 допускаются 3 строки. На 1920 расширяется таблица, не размеры текста. Не фиксировать высоту блоков с потенциально длинными ошибками.

## Типографика

Основной стек: `Inter, Segoe UI, Arial, sans-serif`; пока Inter не включён локально, использовать Segoe UI. Прототип не загружает внешние шрифты. Для идентификаторов допустим `Cascadia Code, Consolas, monospace`, но не делать всю таблицу моноширинной.

| Роль | Размер / line-height / вес |
|---|---|
| Название страницы | 28 / 36 / 650 |
| Название раздела | 18 / 26 / 600 |
| KPI | 28 / 36 / 650, tabular nums |
| Основной текст, таблица | 14 / 20 / 400–500 |
| Подпись, вспомогательный текст | 12 / 18 / 400–500 |
| Кнопка | 14 / 20 / 600 |
| Идентификатор | 12 / 18 / 500 |

В продукте нет текста меньше 12 px. Исключение для сложной оси графика обсуждать отдельно; предпочтительнее меньше делений, чем меньший текст. `font-variant-numeric: tabular-nums`; числа справа, текст слева. Заголовки без CAPS по умолчанию. Длинное название товара — до двух строк и доступное полное название в карточке; tooltip не единственный способ его прочитать.

## Иконки и марка

Единая линейная система 20×20, stroke 1.75–2, круглые концы. Область нажатия ≥40×40. Только существенные пиктограммы: план, данные, исключения, история, параметры, поиск, фильтр, экспорт, раскрытие, проверка. У icon-only кнопок текстовое имя. Декоративные SVG имеют `aria-hidden=true`.

Марка: слово StockPilot в обычном регистре и компактный геометрический знак из трёх вертикальных блоков. Не менять название компании и не изобретать официальный логотип партнёра. Бренд компании в шапке — текстовый контекст, не обещание интеграции.

## Графики

Факт — slate сплошной; скорректированный спрос — teal; прогноз — blue пунктир; известный stockout — светлая янтарная область с текстовой легендой; исключённая операция — круглая марка с контрастной обводкой. Последняя фактическая дата отделяется вертикальной линией. Интервал прогноза рисовать только при реальном диапазоне от модели.

Подписи осей: единица и период. Не соединять неизвестные пропуски сплошной линией. Не заполнять будущие периоды нулями. Tooltip содержит дату, единицу и все доступные серии; те же значения доступны в таблице данных. Оси с нулём по умолчанию для объёмов. Не накладывать деньги и количество на одну шкалу. График иллюстрирует расчёт сервера, а не новую формулу frontend.

## Адаптивность

- ≥1440: полный sidebar, KPI в строку, рабочая таблица; карточка overlay 600 px.
- 1024–1439: compact sidebar 72 px с accessible labels, фильтры переносятся; скрываются вторичные столбцы через меню, а не исчезают данные.
- 768–1023: навигация drawer; таблица внутри горизонтально прокручиваемого региона, закреплён один идентифицирующий столбец без наложения.
- <768: список карточек «товар/риск/количество/действие», фильтры отдельной панелью, detail fullscreen. Для сравнения всех колонок — отдельный табличный режим. Не уменьшать шрифт до 9 px.
- На 320 CSS px и при 200% zoom страницы кроме действительно двумерной таблицы не имеют горизонтального scroll. Исключение таблицы не распространяется на кнопки и пояснения вокруг неё.

## Движение и доступность

Transition 120 ms hover, 180 ms panel, без spring/bounce. Учитывать prefers-reduced-motion, не анимировать смысловые цифры. Цель — WCAG 2.2 AA: читаемый контраст, клавиатура, видимый и не перекрытый фокус, подписи полей и объявление статусов. Минимальный target по 2.5.8 — 24×24 CSS px с предусмотренными стандартом исключениями; внутренний ориентир проекта — 40 px для удобства. Не называть прототип сертифицированным.

Источники: [WCAG 2.2 Quick Reference](https://www.w3.org/WAI/WCAG22/quickref/), [WAI modal dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). Конкретные размеры и палитра выше — проектные решения StockPilot.


## Уточнение зелёного направления

Навигация #10281F, текст на ней #F3F8EE, активная поверхность #2A4430, лайм #B8E986. Лайм используется с тёмным текстом #142C20: белый текст на лайме запрещён. Рабочие таблицы остаются светлыми. Выразительность создают контрастная шапка, компактная геометрия марки и один акцентный KPI; не увеличивать декоративный hero и не ухудшать видимость заказов.
