# Логотип Basqar

`basqar-reference.png` — исходный макет, предоставленный командой.

[`frontend/public/basqar-mark.svg`](../../frontend/public/basqar-mark.svg) — компактная векторная адаптация знака для интерфейса и favicon. Она повторяет зелёные складчатые ленты и белую стрелку из макета; это не исходный векторный мастер логотипа. Фон постера и надпись не входят в файл знака.

В интерфейсе используется компонент `BrandMark`: светлая подложка сохраняет видимость тёмных деталей на боковой панели. Сам SVG имеет прозрачный фон. Соседняя надпись — текст «Basqar», доступное имя сохраняется и при свёрнутом меню.
