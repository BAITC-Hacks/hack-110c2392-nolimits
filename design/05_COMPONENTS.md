# Компоненты и взаимодействия

Использовать семантический HTML и существующий React. Библиотеку компонентов выбирать после инвентаризации зависимостей; макет не требует конкретного vendor. У каждого компонента проверить default, hover, focus-visible, disabled, loading, error и длинный текст.

| Компонент | Контракт | Ключевое поведение |
|---|---|---|
| AppShell | activeRoute, navigation, sourceContext, children | Тёмная лесная панель 224 px; на телефоне доступное меню, никаких обрезанных подписей |
| PageHeader | title, description, primaryAction?, secondaryActions | Один h1; действия переносятся; без фиксированной высоты текста |
| SourceContext | origin, asOf?, calculatedAt?, stale, warnings | Неизвестные даты явно неизвестны; синтетика заметна без hover |
| MetricCard | label, value, unit?, scope, completeness?, onClick? | Значение и область; интерактивная карточка — button/link, обычная — не tab-stop |
| StatusBadge | kind: risk/decision/quality, value, label | Иконка + текст, цвет не единственный сигнал; нет клика без действия |
| FilterBar | controlled filters, options, resultCount, onChange, onReset | Значения сохраняются при drawer; очистка не сбрасывает всю страницу |
| SearchField | value, onChange, label, onClear | Постоянное accessible name; debounce для серверного поиска; Escape очищает только по документированному правилу |
| DataTable | rows, columns, rowKey, sort, selection, pagination | Нативная table; th scope, aria-sort; числа справа; открытие через отдельную кнопку |
| ProcurementCard | тот же view model, что строка | Название, склад, риск, решение, количество и стоимость; нет отдельной бизнес-логики |
| SelectionBar | count, eligibleCount, reasons, actions | Не скачет высота; область действия явно написана |
| MoneyValue | amount: number/null, currency, completeness | 0 → «0 ₸»; null → «Нет цены»; частичная сумма подписана |
| QuantityField | string draft, unit, precision, min, step, constraints | Хранит ввод строкой до валидации; не округляет молча |
| DrawerDialog | open, title, dirty, onRequestClose | Modal semantics, фокус внутри, Escape, возврат фокуса, блокировка фонового скролла |
| CalculationTrace | terms, raw, rounded, constraints | Последовательные строки с единицами, финальная величина; не декоративная формула |
| DemandChart | points, unit, period, annotations, loading | Табличная альтернатива, разрыв на неизвестных значениях, подписи серий |
| ImportReport | accepted, rejected, issues, source | Ошибки по полю/строке, фильтрация, доступная выгрузка отчёта |
| EmptyState | reason, title, description, action? | Различает отсутствие данных и пустой фильтр |
| InlineAlert | severity, title, message, action? | Постоянные ошибки внутри соответствующего блока |
| Toast | message, severity | Только краткая обратная связь; aria-live, не единственный способ узнать ошибку |

## Кнопки и поля

Primary — максимум одно главное действие на смысловой блок. Secondary — контур; tertiary — текст. Destructive красный только для опасного действия, а не для приоритета закупки. Loading сохраняет ширину кнопки, текст меняется на конкретный: «Сохраняем…». Disabled сопровождается доступной причиной рядом, не только tooltip, который нельзя открыть на телефоне.

Все icon-only кнопки имеют aria-label и зону не меньше 40×40; на touch 44×44. Tooltip появляется по focus и hover, закрывается Escape; критические объяснения никогда не живут только в tooltip. Поля имеют label, подсказку и текст ошибки через aria-describedby; invalid через aria-invalid. Не полагаться на placeholder как название.

## Таблица

Сортировка — кнопка в заголовке, состояние aria-sort на th. Checkbox имеет имя «Выбрать [SKU], [склад]». Header checkbox поддерживает mixed. Вложенный checkbox/кнопка не открывает строку через bubbling. Если строка полностью кликабельна для мыши, альтернативная семантическая кнопка остаётся обязательной.

Sticky заголовки и колонки не перекрывают фокус. У обрезанного имени есть доступный полный текст в карточке; числовые значения не обрезаются многоточием. Пагинация показывает диапазон, общее количество и размер страницы. После удаления/фильтрации последней строки перейти на существующую страницу. Выбор не хранить по индексу массива.

## Диалог

Предпочтительно native dialog либо проверенный доступный primitive. При открытии фокус на заголовок или первое безопасное поле, при закрытии — инициатору. Tab/Shift+Tab не уходят за пределы. Escape вызывает ту же проверку dirty, что крестик. Во время сохранения не терять ответ и не закрывать форму автоматически при ошибке. Backdrop закрывает только чистую форму; на мобильном фон не прокручивается.

Основа поведения: [WAI-ARIA modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). Реальную поддержку скринридеров проверить отдельно; наличие role не равно полной доступности.

## График

Факт — серый сплошной, восстановленный спрос — teal, прогноз — синий пунктир. Вертикальная граница начала прогноза. Stockout — диапазон, anomaly — отдельный маркер. Не соединять неизвестные дни с нулём. Tooltip: дата, каждая серия с единицей, тип события. Никакого «confidence 98%», пока нет калиброванной модели и соответствующего API. На телефоне график сохраняет минимум 180 px высоты, легенда переносится. Область графика не захватывает вертикальный скролл страницы.

## Тексты

Использовать «Позиция», «Склад», «Поставщик», «Остаток», «В пути», «Рекомендовано», «К заказу», «Утверждено». Не заменять их случайными «юнитами», «сигналами», «AI insights». Краткая причина объясняет наблюдение и последствие: «Поставка ожидается после периода расчёта; её объём не уменьшает текущий заказ» — только после реализации такой логики. Текущий backend учитывает транзит иначе, UI не должен обещать исправленный алгоритм заранее.
